🍨 Ice Cream Outlet API

A production-ready Django REST API with dual databases, analytics pipeline, and background processing.

This project demonstrates a real-world backend architecture:

  • Django + DRF backend
  • PostgreSQL (transactional) + MySQL (analytics)
  • Celery + Redis for background jobs
  • Automated analytics sync
  • Deployed on Render
